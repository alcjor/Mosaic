# PR sheets

Overview sheets for Mosaic pull requests, drawn by `scripts/pr_sheet.py` on `main` and shown at
the top of each PR body. One folder per PR, one file per commit and theme
(`pr-<n>/<sha7>-light.svg`, `pr-<n>/<sha7>-dark.svg`). Files are never overwritten.

This branch never merges into `main`.
