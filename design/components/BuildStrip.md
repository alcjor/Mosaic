# BuildStrip

The five state icons in build order, Tessera → Pattern → Build → Built mosaic → Embedded, each labelled: the picture of how Mosaic works.

- Use it once per piece, near the top: under the tagline in the repository README and on the docs home page, or under "How it works" next to the StepRows.
- Icons 56px (never below 24px, the pattern icon's minimum), chevrons in `ink-muted`, names 13px bold in `heading`, one `caption` each in `ink-muted`.
- The icons are inline SVG bound to `mark-base`, `mark-mid`, `mark-piece` and `mark-line`, so one markup serves paper and navy. Where only an image will do (a README on GitHub), use `mosaic-build-strip-light` / `-dark` from Icons, with the labels as text below.
- Keep the order and the five names. Captions may change with the audience; keep them to four words or fewer.
- The middle icon is the logo mark: don't add a wordmark to it or swap it for the lockup.
