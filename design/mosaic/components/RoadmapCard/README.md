# RoadmapCard

One phase of the roadmap: a 20px accent ShardBadge, a 13px bold title and one `caption` line, inside a `border` outline with `radius-md`.

- Lay four in a row (`repeat(4, minmax(0, 1fr))`, gap `space-3` − 2px) under the label "Roadmap · every phase is usable on its own".
- Titles after the first start with "+" to show each phase adds to the last: Linked ops manual, + Telemetry, + Cross-mission, + AI and MBSE.
- Badge colours follow what each phase adds: blue (reference data), turquoise (telemetry), navy (the pattern across missions), saffron (AI).
- Never add dates or effort estimates unless they are real; use placeholders like [Q2 2027].
