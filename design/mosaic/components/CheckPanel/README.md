# CheckPanel

A `surface-tint` panel with a `panel-title`, three or four check-marked claims and one closing `caption`: the place for the cost and risk argument.

- Background `surface-tint`, radius `radius-md`, padding `space-3` + 2px / `space-4`.
- Claims start with a bold two- or three-word lead ("No re-entry:") and end with a short fact.
- The closing caption carries the positioning idea: a step towards the MBSE and PLM tools being adopted. Never "complements" and never an import promise.
- One per piece. It is the only filled box on a page; everything else sits on paper.
