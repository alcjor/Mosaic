# SectionLabel

An uppercase, tracked label in `accent` that opens every section of a MOSAIC piece.

- Style: `section-label` (12px, 600, 1.6px tracking), `text-transform: uppercase`, colour `accent`.
- Markup: a real `<h2>` so the document keeps its outline.
- At most 6 words. A middle dot (`·`) can add a short qualifier ("Roadmap · every phase is usable on its own").
- Space below it: `space-2` to the first item.
- On navy, use `shard-tcs` instead of `accent`.
