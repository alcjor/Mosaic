# Statement

One sentence that carries the concept, set in `statement` with a bold `accent` lead-in.

- Use it once per piece, directly under the header band: usually the Reverse MBSE definition, verbatim.
- Lead-in: the term being defined, followed by a colon, in 700 weight and `accent`.
- Body of the sentence: 500 weight in `heading`; `text-wrap: balance`.
- Follow it with a ShardStrip when it sits between a navy header and white body.
