# Imagery

Trencadís artwork, generated by script.

- `banner-assembly-glaze`: the current hero, used as the A4 one-pager header (3:1). Grey fragments on the left align as they near curved bands of tiles; each finished band carries one glaze colour. Keep text in the left third.
- `banner-assembly-blue`: the same composition in corporate blues only.
- `mosaic-hero-glaze`, `mosaic-hero-blue`: 16:9 title images (2880 × 1620) in the assembly style, with mark, wordmark, category line and tagline ("No rebuild, no re-entry." in saffron).
- `mosaic-hero-glaze-clean`, `mosaic-hero-blue-clean`: the same artwork without text, for your own titles. Keep text in the left 40%.
- `flyer-strip`: the ShardStrip divider.

The assembly banner is decorative: its colours show "structured vs unstructured", not real data, so it carries no data caption.
