# Reading cases

Files that the reading rules of section 3.8 open or refuse. Every reader (the Python reader in
`mosaic_format` and the TypeScript kit) opens each file whose `opens` is true in `cases.json`
and returns its header as `cases.json` records it, and refuses every other file for the rule it
names, with an error that names the file and what failed.

Generated by `scripts/make_reading_files.py` from the conforming files of
`scripts/make_invalid_files.py` (invented data). Hashes are rewritten after each change, so a
file breaks only its one rule. `mosaic check` passes the files that open (`mosaic.mosaic` with
`tessera.tessera` as its piece) and fails the others.

| File | Rule | Made by |
| --- | --- | --- |
| `tessera.tessera` | opens | The conforming tessera |
| `mosaic.mosaic` | opens | The conforming mosaic, with vectors, whose first piece is `tessera.tessera` |
| `wal.mosaic` | opens | The conforming mosaic in WAL mode (bytes 18 and 19 of the SQLite header are 2), with no write-ahead log beside it: a single SQLite 3 database file (section 3.1) |
| `empty.mosaic` | `application_id` | An empty file, which SQLite opens as an empty database |
| `not-sqlite.mosaic` | `sqlite` | A text file, not a SQLite database |
| `application-id.mosaic` | `application_id` | `application_id` is 0 |
| `user-version.mosaic` | `user_version` | `user_version` is 2 |
| `format-version.mosaic` | `format_version` | The header's `format_version` is `0.2` |
| `newer-minor.mosaic` | `format_version` | A newer minor version: `format_version` is `0.2` and the header has an added column; refused for its version, not its schema |
| `header-column.mosaic` | `schema` | The header has an added column, but `format_version` is `0.1` |
| `schema-extra-table.mosaic` | `schema` | A table that `format.sql` does not define |
| `schema-dropped-index.mosaic` | `schema` | The index `edge_in` of `format.sql` is dropped |
| `no-header.mosaic` | `header` | The header row is deleted |
| `header-kind.mosaic` | `header` | The header's `kind` is `other` |

Rules:

- `sqlite`: The file is not a SQLite 3 database (section 3.1)
- `application_id`: `PRAGMA application_id` is not `0x4D4F5341` (MOSA) (section 3.1)
- `user_version`: `PRAGMA user_version` is not 1, that of format 0.1 (sections 3.1 and 9)
- `format_version`: The header's `format_version` is one the reader does not implement, a newer minor version included (sections 3.8 step 2 and 9)
- `schema`: The schema is not exactly the objects of `format.sql` (section 3.1)
- `header`: The header is not exactly one row of a known kind (section 3.3)
